## 3.3 兩種角色評估的組成成分

每一種評估皆透過具名的組成成分（components）予以特定化，因此一項評估可以是「部分的」——危及某些角色成分而讓其他成分完好無損，或開啟某些成分而其他成分仍感受威脅。這種成分式結構對第 4 節的命題具有重要性，因為不同的線索關聯於不同的成分：一項核心任務的示範所觸及的是職業身分（occupational identity）與專業能力的市場價值（market value of expertise），而一則組織重組公告所觸及的則是僱用安全（employment security）。表 2 列出這些成分。較長時程的「就業能力」（employability）被視為相關但有所區別的關切，而非第五個威脅成分，因為它是相對於外部勞動市場、而非相對於當前角色而受到評估。

**表 2.** *角色威脅評估與角色機會評估的組成成分。*（*Components of role threat and role opportunity appraisal.*）

| 成分 | 所評估的內容 |
|---|---|
| ***角色威脅評估——受危害的成分*** |  |
| 僱用安全 | 自己的工作或員額是否面臨風險。 |
| 專業能力的市場價值 | 自身技能的市場價值是否正被侵蝕。 |
| 角色自主性（role autonomy） | 對自己如何工作的裁量權（discretion）與控制是否正被限縮或標準化。 |
| 職業身分與地位（occupational identity and status） | 自身角色的獨特性、意義與地位是否正被降級。 |
| ***角色機會評估——賦能的成分*** |  |
| 角色增益（role augmentation） | AI 是否拓寬自己所能完成的任務範圍。 |
| 角色提升（role elevation） | AI 是否吸納較低價值的任務，使自己轉向判斷性、關係性、創造性或策略性的工作。 |
| 角色再造（role reinvention） | AI 能力是否能被建入一個重新界定的專業身分，並成為角色價值的新基礎。 |
