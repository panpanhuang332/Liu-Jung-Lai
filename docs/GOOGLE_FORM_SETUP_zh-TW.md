# Google 表單設定指南（讀者提問）

本網站的「讀者提問」頁使用 Google 表單收集問題。表單由柳蓉同學自己的 Google 帳號建立與持有；網站只放連結與內嵌畫面，**不需要**任何後端、API 金鑰或登入功能。

## 一、建立表單

1. 以自己的 Google 帳號開啟 https://forms.google.com ，點「建立新表單」。
2. 表單標題建議：「讀者提問｜Liu-Jung Lai 學術網站」。
3. 表單說明建議寫明：提問不會自動公開；若同意公開，將依勾選以匿名或署名方式刊登。

## 二、建議欄位

| # | 欄位 | 類型 | 必填 |
|---|---|---|---|
| 1 | 姓名或暱稱 | 簡答 | 否 |
| 2 | Email（若希望收到回覆） | 簡答 | 否 |
| 3 | 所屬單位 | 簡答 | 否 |
| 4 | 提問類別 | 單選（論文內容／研究方法／研究方向／其他） | 是 |
| 5 | 相關論文 | 單選（當賦能敘事反噬／整合—可替代性弔詭／作者研究方向／不特定） | 是 |
| 6 | 相關章節／命題／假設／圖表 | 簡答（例：§2.3、P3、H4、圖 1） | 否 |
| 7 | 問題內容 | 詳答 | **是** |
| 8 | 是否同意將問題整理後公開 | 單選（同意／不同意） | 是 |
| 9 | 若公開，是否匿名 | 單選（匿名／可署名〔以第 1 題名稱〕） | 是 |
| 10 | 隱私告知與同意 | 核取方塊（「我了解主辦者將以上述方式處理我的提問」） | 是 |

隱私告知文字建議：「您的提問與聯絡方式僅供作者回覆與整理公開問答之用，不會提供第三方；未經您同意不會公開您的姓名或 Email。」

## 三、表單設定（右上角「設定」）

- **回應**：不勾選「限制為 1 次回應」（避免強制 Google 登入）。
- **不**勾選「收集電子郵件地址」（Email 已是選填欄位）。
- **不**使用檔案上傳題型（檔案上傳會強制登入並占用雲端空間）。
- 「知道連結的任何人」皆可填寫（預設即是）。
- 建議在「回應」分頁開啟「收到新回應時傳送電子郵件通知」。
- 在「回應」分頁點綠色試算表圖示，把回覆連結到**自己持有**的 Google Sheet，方便整理。

## 四、把表單接到網站

1. 表單右上角「傳送」→ 鏈結圖示，複製網址（可勾選「縮短網址」）。
2. 「傳送」→「< >」（嵌入 HTML），複製 iframe 的 `src` 網址（形如 `https://docs.google.com/forms/d/e/…/viewform?embedded=true`）。
3. 編輯網站檔案 `lib/site-config.ts`：

```ts
googleForm: {
  publicUrl: "（第 1 步的網址）",
  embedUrl: "（第 2 步的 src 網址）",
  enabled: true,
},
```

4. 存檔、commit、推送（或直接在 GitHub 網頁編輯此檔）。GitHub Actions 部署完成後，提問頁就會出現「開啟提問表單」按鈕與內嵌表單。

## 五、注意事項

- `enabled: false` 或網址留空時，提問頁只顯示「表單準備中」，不會壞掉。
- **絕對不要**把 Google Sheet 的回覆內容、讀者 Email commit 進 GitHub。
- 公開一則問答的流程見 `docs/HANDOFF_zh-TW.md` 第 6 節。
- 網站或 Claude Code 都**不需要、也不應該**取得您的 Google 帳號權限。
